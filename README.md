# LocalService

Маркетплейс місцевих побутових послуг — платформа для з'єднання мешканців міста з фахівцями (сантехніки, електрики, прибирання, репетиторство тощо).

## Технологічний стек

- **Backend**: Node.js + TypeScript + Express
- **Frontend**: React 18 + TypeScript
- **База даних**: PostgreSQL 15 + Prisma ORM
- **Кеш**: Redis
- **Хмара**: AWS (EC2, S3, RDS)

## Запуск проєкту

```bash
npm install
npm run dev
```
